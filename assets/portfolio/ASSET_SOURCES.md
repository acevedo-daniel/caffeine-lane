# Procedencia y derechos de imágenes del portfolio

## Declaración de procedencia

El propietario del proyecto confirmó el 29 de julio de 2026 que todas las
imágenes bajo `source/` se descargaron de [Unsplash](https://unsplash.com/).
Se convirtieron a WebP con el lado mayor limitado a 1600 px para su uso en
`seed_portfolio`.

La [licencia de Unsplash](https://unsplash.com/license) permite descargar,
copiar, modificar, distribuir y usar las imágenes gratuitamente, incluso con
fines comerciales, sin requerir permiso ni atribución. No permite venderlas sin
una modificación significativa ni compilarlas para crear un servicio similar o
competidor de Unsplash.

La atribución no es obligatoria bajo esa licencia, pero se recomienda conservar
la URL y el autor original cuando estén disponibles. Los WebP actuales no
contienen EXIF ni identificadores de la fotografía original; por eso no es
posible reconstruir de manera fiable la página individual o el fotógrafo de
cada archivo. Si se recuperan esos datos, deben añadirse a esta tabla antes de
un cambio de imagen.

## Regla de mantenimiento

Todo archivo nuevo bajo `source/` debe añadirse a este inventario con su URL de
Unsplash y autor, si están disponibles, antes de quedar expuesto públicamente.
