# Procedencia de imágenes del portfolio

Los archivos bajo `source/` fueron aportados al repositorio por el propietario
del proyecto el 29 de julio de 2026. Se convirtieron a WebP, con el lado mayor
limitado a 1600 px, para la semilla `seed_portfolio`.

Antes de desplegarlos públicamente, el propietario debe confirmar que dispone
de los derechos de publicación para cada fotografía y para las marcas, personas
o lugares identificables que aparezcan en ella. Este archivo registra la
procedencia; no sustituye una licencia ni concede derechos de terceros.

`source/reserved-slider/reserved-slider-01.webp` proviene de
`static/Media/coffeline-girl-1.jpg`. Está reservado para ser la primera imagen
del slider en una tarea posterior y no forma parte de `PORTFOLIO_POSTS`.
